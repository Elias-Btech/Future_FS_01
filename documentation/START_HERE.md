## 🚀 Quick Start - 3 Options

### Option 1: Push to GitHub Now (5 minutes)

**Follow this guide:**
📖 **[PUSH_TO_GITHUB_NOW.md](PUSH_TO_GITHUB_NOW.md)**

Quick commands:
```bash
git init
git add .
git commit -m "Initial commit: Professional portfolio"
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git push -u origin main
```

### Option 2: Customize First (15 minutes)

1. **Update README.md:**
   - Replace `YOUR-USERNAME` with your GitHub username
   - Replace `YOUR-REPO` with your repository name
   - Update live demo URL
   - Update contact information

2. **Update Personal Info:**
   - Edit `index.html` with your details
   - Replace photos in `assets/`
   - Update resume PDF

3. **Then push to GitHub** (see Option 1)

### Option 3: Full Setup (30 minutes)

1. **Run setup script:**
   ```bash
   bash scripts/setup.sh
   ```

2. **Configure database:**
   - Edit `config/db.php`
   - Import database schema

3. **Customize content:**
   - Update personal information
   - Add your projects
   - Add your certificates

4. **Push to GitHub** (see Option 1)
